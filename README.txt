hind_luxury_veil — متجر 3301

التشغيل محليًا:
1. ثبّت Node.js 18 أو أحدث.
2. افتح الطرفية داخل مجلد المتجر.
3. شغّل: node server.js
4. افتح http://localhost:8080

ربط أسعار ZR Express الحية:
- افتح حساب التاجر في ZR Express / Procolis وفعّل API.
- احصل على Token وKey من لوحة التاجر.
- لا تضع بيانات API داخل index.html ولا ترسلها للزبائن.
- اضبط متغيرات البيئة على الخادم قبل تشغيله:
  ZR_TOKEN=رمزك
  ZR_KEY=مفتاحك
  ZR_ORIGIN_WILAYA=16
  PORT=8080
- أعد تشغيل الخادم. سيستدعي المتجر /api/rates من الخادم، الذي يتصل بخدمة dzship لتقدير أسعار حساب ZR Express. إذا لم تكن المفاتيح مهيأة، يعرض المتجر الأسعار المحلية التقديرية ولا يدّعي أنها أسعار مباشرة.

مثال Windows PowerShell لجلسة واحدة:
$env:ZR_TOKEN="ضع_الرمز_هنا"
$env:ZR_KEY="ضع_المفتاح_هنا"
$env:ZR_ORIGIN_WILAYA="31"
node server.js

ملاحظات:
- يجب أن تكون الولاية الأصلية هي الولاية التي تُشحن منها الطرود.
- API الأسعار يعتمد على صلاحية بيانات التاجر والتغطية والتعريفة المتاحة للحساب. راجع النتيجة مع ZR Express قبل الاعتماد التجاري.
- لا يتم إنشاء بوليصة شحن تلقائيًا في هذه النسخة؛ إرسال الطلب للمتجر ما زال عبر WhatsApp.
- الأسعار المحلية البديلة تقديرية، وليست تعريفة رسمية مؤكدة.
- قائمة البلديات العامة قد تحتاج اتصال إنترنت.
